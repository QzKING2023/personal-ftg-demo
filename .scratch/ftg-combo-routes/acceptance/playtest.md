## 0 通用约定（先读，各样本章节不再重复）

### 0.1 键位（与 `project.godot` 输入映射一致）

| 功能 | 物理输入 | 说明 |
| --- | --- | --- |
| 水平移动 | A/D 或 ←/→ | **物理 D 是「向右」，不是动作 D** |
| 下 | S 或 ↓ | 蹲下/搓招的下方向 |
| 跳跃 | Space 或 ↑ | 与前/后组合为 9/7 斜跳 |
| 动作 A / B / C / D | U / I / K / J | **动作 D 用 J**；I/K 单键最多等 3 帧配组合，U/J 直出 |
| 木桩防御 | G 循环 | 无→站防→蹲防→空防（逐帧请求，木桩无自主决策） |
| **木桩跳跃（票据 05 新增）** | **T**（可按住 ←/→ 带水平） | 空闲木桩按普通跳离地（滞空与玩家跳一致），下落中可被对空首击；忙碌时忽略 |
| 重置 | R | 回出生位（玩家 x240 / 木桩 x620，见 §0.5） |

- 「动作 D」= 招式记号里的 D 键招（5D/6D/2D/j2D/j214D 等），按 **J**。
- 「物理 D」= 键盘右方向键，只用于移动和搓招方向，永远不出招。
- 236/214 是**方向序列**不是物理键：236 = 下→下前→前，再按攻击键；214 = 下→下后→后，再按攻击键。数字方向按**当前面向**折算（面向右时 236 的"前"=D，214 的"后"=A；面向左时互换）。

### 0.2 面向、镜像与换边

- 玩家每帧自动面向木桩：站在木桩左侧=面向右（搬运朝右墙），右侧=面向左（朝左墙）。**双面向练习 = 换到木桩另一侧再做一遍**。
- 镜像规则：左右面向只交换水平键（A↔D、←↔→），U/I/K/J、Space、S 与帧号不变。236/214 的"前/后"按新面向折算。
- 换边后：玩家面向当帧翻转（事件行「换边：命中穿越，下一帧面向 →/←」）。**换边后的方向输入按新面向折算**；R1 长线中 6D 用换边后的"前"（与初始方向相反），第二次换边后方向恢复初始面向（详见 §1/§2 各步）。

### 0.3 口径

- F = 60Hz 物理输入帧（命中后 8 个冻结帧输入仍采样）；N = 正常战斗帧。玩家步骤用**可观察节拍**（画面与 HUD），不要求读内部帧号/高度/墙距；§各样本末的参考帧表仅供复现与录像对账。
- 连段计数：招式数与 HIT 数分别记录（236C 两段=1 招 2 HIT；jc 不计攻击）。
- 首次 `COMBO_ENDED` 后的命中属于**新连段**（状态行 hit 数从 1 重新起算），不能拼进原路线。
- 合法域外（站位/距离超出适用范围）的成功允许，不算本样本失败证据；域内失败按 §0.6 分类记录。

### 0.4 HUD 阅读（反馈与实际结算一致，票据 01–10 累计）

| 行 | 位置 | 内容 |
| --- | --- | --- |
| 状态行 | 右上 | 木桩受击状态（低浮空/滑行/弹地/空中高度/追击窗剩余）、防御与防僵、连段 hit/伤害、起手等级与三层修正、普通连接失败原因 |
| 事件行 | 状态行内 | 低浮空触地、Rekka 分支锁定、滑行开始、弹地触地（含追击窗）、蓄力提交（含按住帧数/松开走普通版）、换边（命中穿越）、被防（含被防硬直）、木桩防御拒绝原因、连段结束原因（收尾招式/取消窗口关闭/收招未接续/木桩自然受身/普通倒地） |
| 诊断行 | 左下 | 帧号、面向、姿态（停顿/准备/落地/冲刺）、招式与属性、蓄力龄/蓄力版、位移（→/←·穿越/墙截）、**缓存（如 `5B[I] 余3帧`）**、跳槽、按住键、方向序列、取消目标与窗口年龄、Rekka 派生窗、空技落地接缝 |

关键区分（反馈忠实于实际状态）：

- **身后停止 ≠ 恢复结束**：换边/位移停止后，诊断行「招式」列仍显示 `5[D]`（恢复中）；招式列变 `—` 才是恢复结束。停止当下不能出招。
- **M 等待/预输入 ≠ 提前执行**：D 后/弹地后的 5B 可在恢复中预输入（诊断行缓存列出现 `5B[I] 余N帧`），恢复完成才消费；缓存余帧耗尽即作废（诊断行消失、事件行「连段结束：收招未接续」）。预输入不绕过恢复、不把空中 B 变地面 B。
- **HIT/BLOCK/WHIFF 分清**：命中=闪白+连段计数+取消资格；被防=事件行「攻击被X挡下」（无伤害无连段，无命中确认资格）；挥空=无接触（无资格）。
- **2C 命中 ≠ 已收尾**：2C 命中后木桩进入「低浮空（N）」，须保持中立等「低浮空触地 → 普通倒地」事件与状态行「普通倒地」——那才是首次实际倒地/终点；低浮空中再出招属于倒地前补击（改变终点语义，不算成功路线）。
- **弹地触地事件 ≠ 可以立即打**：追击窗剩余帧在状态行；玩家自己还须完整落地恢复后才能接 5B。

### 0.5 初态进入通用方法

出生位：玩家中心 x240、木桩中心 x620（R 重置即回此位）。此时双方接地中立、面向右、木桩到右墙 r≈310px、间距 g≈368px。

1. **调间距 g**（所有样本都要 g≤18px ≈ 双方几乎贴身，中心距约 ≤30px）：走向木桩到贴近。目测参照：12px 身宽，g≤18 即空隙不足 1.5 个身位；地面中央有 6px 中心标记可辅助。
2. **调墙距 r**（移动木桩只能靠打击推离——木桩无自主移动）：
   - 要木桩**靠近某面墙**（R2 短线、R3 原版边）：站到反侧用普通攻击（如 5B 连打，或 236C 两段大推离）把它推向该墙；r≤12px ≈ 木桩背缘几乎贴住墙皮（不足一个身位）。
   - 要木桩**远离墙**（R1 长线 r≈496–700）：从出生位**换到木桩右侧**（面向左、搬运朝左墙）即得 r≈590；或向左推后再换侧。
   - 每次推打后等状态行回「中立」（倒地/硬直计时结束）再开始。
3. **清输入**：开始前中立空拍约 1 秒（清空动作缓存 6F 与方向历史）。
4. **R4-A 初态**：站定后按 **T** 让木桩普通跳（可按住 ←/→ 让它带水平漂移），在它**下落段**出 6A（见 §8）。
5. 面向由站位自然决定（§0.2）；双面向=两侧各做一遍。

## 3 R2-B 抵墙短线（B 起手）
