# 04: jump cancel 与首次空中追击

**What to build:** 命中配置允许 jump cancel 的地面招式后，玩家可以使用 Space 转入空中并接上 jA，同时不会获得二段跳或无限刷新滞空资源。

**Blocked by:** 03: 方向派生招式与浮空受身.

**Status:** ready-for-human

- [x] C/236C 只有在命中确认且招式配置允许时才能被 Space jump cancel；未配置招式的 Space 不产生连段追击资格。
- [x] Space 独立于动作键缓存，不会被缓存、消费或覆盖动作键输入。
- [x] jump cancel 后可按指定语义从 jA 开始空中追击；空中不能二段跳，后续追击不能刷新木桩滞空资源。
- [x] 默认玩家跳跃持续 40 个物理帧、木桩浮空滞空 48 个物理帧，参数可调且状态反馈可观察。
- [x] 测试覆盖命中/挥空 jump cancel、Space 独立性、jA 起手、二段跳禁止和有限滞空资源。

## Comments

**2026-09-13 实现完成（agent）：**

- jump cancel 在招式数据中表达：`MoveData.jump_cancel_targets`（空中追击起手招式 id 列表，空列表 = 不支持）。默认表 5C/236C 配置 `["jA"]`；新增 jA（空中姿态，startup 4/active 6/recovery 10、伤害 8、击退 120，普通命中 GROUND_HITSTUN——不重起跳、不刷新滞空，复用 issue 03 的“普通命中只在地面附带击飞”规则）。
- 资格判定 `_can_jump_cancel()`：招式配置 + 命中确认 + 连段活跃 + 木桩可追击 + 取消窗口内（与动作键取消同一 0–8 帧窗口），在运动阶段处理 Space：起跳、清除当前招式回中立、保留连段并开放配置的空中追击资格。挥空、未配置招式（5A）、窗口关闭后（第 9 帧）的 Space 一律无效且不动连段状态。
- 追击资格：消费缓存在空闲起手时只有“连段活跃且属于 jump cancel 配置起手”的空中招式才按合法接续（followup）起手，能命中浮空受击中的木桩；普通中立跳跃后的 jA 仍是独立招式，即使把木桩摆进命中框也打不中。jump cancel 落地仍未接续空中起手时资格作废，连段以 MOVE_RECOVERED（收招未接续）结束；木桩浮空处理不受影响。
- Space 独立性：Space 只走 `FrameInput.jump_pressed`，不进入单槽动作缓存（既有设计）；测试验证 5A 命中后按 Space 不跳、不打断招式、不破坏随后 B 的缓存取消。空中 Space 一律无效（跳跃分支都要求 on_ground），jump cancel 后连按 Space 无第二次向上速度、滞空仍恰为参数帧数（无二段跳）。
- 参数：`JUMP_VELOCITY`(-540) 移除，改为 `PLAYER_JUMP_AIRTIME_FRAMES=40` + `jump_velocity()` 换算（与 `float_launch_speed()` 同一积分方式：起跳帧当帧不加重力，落地帧恰为起跳帧+40）；木桩滞空沿用 `DUMMY_FLOAT_AIRTIME_FRAMES=48`。测试断言两个默认值与“落地-起跳恰为参数帧数”（改参数即改滞空）。
- 追击不刷新滞空：jA 命中浮空木桩只改水平速度，木桩仍在原始浮空抛物线上按 48 帧落地（测试断言落地帧 = 命中帧+48 且 y 速度只按重力演化）；落地后按剩余硬继续倒地处理。
- 训练场：状态栏新增“玩家 地面/空中”姿态段（为 issue 05 的姿态显示预留）；提示文本不变。
- 测试：session 239 项（新增 35：三重门槛与窗口关闭边界、236C/5C 两条 jump cancel → jA 追击全路线帧序、Space 缓存独立性、二段跳禁止与 40 帧滞空、长浮空下落地断连、中立跳跃 jA 禁追击、默认表 jA 起手；原“空中无配置招式”测试改用仅地面招式表保留语义）+ smoke 50 项（新增 11：键盘 236C → Space → jA 全流程、姿态显示、追击命中计数与伤害、无额外命中）。全部通过。
- 待人工试玩：jump cancel 后 jA 的节奏（Space→A 间隔）、40 帧跳跃与 48 帧滞空的相对高度差是否够 jA 全程命中、5C 与 236C 两条起跳路线手感；试玩后直接改 `GameParams` / `MoveData`，不需要动 `CombatSession`。
- 评审注记（2026-09-13）：① jump cancel 资格在运动阶段判定（起跳当帧需积分位置），与第 5 阶段的动作键取消在木桩浮空受身的边界帧可能相差一帧；连段与追击资格的最终语义一致（受身当帧仍结束连段、AIR_RECOVERED 不可追击），已收敛为共用的 `_cancel_window_open()` 窗口判定。② 追击命中（jA）把浮空木桩转为地面受击硬直的空中滞停形态（与地面命中击飞的微浮同构，硬直落地后续耗）；追击后的木桩不会空中受身，一律落地恢复——是否需要在空中追击中保留浮空受身语义留给 issue 05 的状态转换验收。③ 默认参数下（浮空硬直 36 < 滞空 48）jump cancel 不接续时通常先由浮空受身断连，落地作废路径只在硬直 ≥ 49 的配置下触发（测试用硬直 60 覆盖）。④ 同帧 Space+A：A 在输入帧按地面姿态解析为 5A，起跳后姿态不符被丢弃——确定性一致，节奏手感留待试玩。
