# 03: 方向派生招式与浮空受身

**What to build:** 玩家可以用独立方向序列触发派生招式并将木桩带入浮空，方向识别和木桩自然受身不会被动作键缓存混淆。

**Blocked by:** 02: 稳定地面路线与输入缓存.

**Status:** ready-for-human

- [x] 方向输入拥有独立的默认 24 帧历史窗口，年龄 0–23 有效，过期时不能触发派生招式，也不占用动作键缓存。
- [x] `236C` 和 `214D` 能被识别、消费方向序列并锁定对应派生招式；A/B/C/D 的逻辑语义在招式数据中独立表达。
- [x] C 的命中结果能将木桩置于浮空受击状态；浮空后续不依赖隐式普通连接。
- [x] 木桩浮空受身时立即结束连段，落地后才恢复中立；收尾和自然受身仍分别判定。
- [x] 测试覆盖方向窗口过期、方向消费、派生锁定、浮空状态、浮空受身和落地恢复。

## Comments

**2026-09-13 实现完成（agent）：**

- 方向历史：`FrameInput` 新增 `down_held`（S/↓），会话把（水平轴、下方向、面向）折算成面向相对的小键盘数字，只记录变化条目（含中立 5，匹配时滤除并折叠相邻重复），与原型语义等价。窗口 `DIRECTION_BUFFER_FRAMES=24`：年龄 0–23 有效、24 先过期（输入阶段先清理再记录）。方向输入不进动作键缓存。
- 方向派生在招式数据中表达：`MoveData.direction_derivation`（如 "236C" = 方向序列 236 + 动作键 C），`_resolve_action` 在动作键按下帧用历史尾部 endsWith 匹配（多匹配取序列最长者），识别即消费整段方向历史并把单槽缓存锁定为派生招式；CombatSession 不按字母特判。空中不参与派生（沿用 jX 解析）。
- 招式表：新增 5C（startup 6/active 5/recovery 16、伤害 14、击退 140）与 236C（6/5/18、18、200）、214D（7/5/20、22、400，收尾）；5A 取消目标加 236C、5B 加 214D（对齐原型路线 5A→236C、5B→214D）。浮空招式 hit_result=LAUNCH、硬直 `FLOAT_HITSTUN_FRAMES=36`、起跳速度由 `DUMMY_FLOAT_AIRTIME_FRAMES=48` 换算（半隐式欧拉下滞空恰好 48 帧）。
- 浮空/受身状态机：`DummyState` 新增 AIR_HITSTUN（浮空受击，滞空期间逐帧消耗）与 AIR_RECOVERED（空中已受身）。浮空硬直归零 → 浮空受身：当帧结束连段（DUMMY_RECOVERED 原因），落地帧才恢复中立并发 DUMMY_RECOVERED 事件；硬直未耗尽就落地 → 转地面硬直、落地当帧继续消耗（与地面受击的落地帧一致），归零自然受身。收尾（含 214D）照旧保留倒地处理。
- 命中门槛：AIR_HITSTUN 与地面硬直一样只允许“连段活跃 + 合法接续”命中（浮空后续不依赖隐式普通连接，独立招式够得着也打不中）；AIR_RECOVERED 落地前不可命中。LAUNCH 命中必定重起跳给完整滞空（原型行为；普通追击命中不刷新滞空，为 issue 04/05 的滞空资源规则留位）。
- 结算顺序补强：新增 `_dummy_fresh_hitstun`——命中的当帧不消耗新硬直（对齐原型“先刷新、后落地/自然受身”，也让命中帧后 `hitstun_left` 恰为配置值；对 issue 02 地面路线的唯一影响是 knockback_up=0 的贴地命中晚一帧归零，默认招式全部有 pop，现有测试不受影响）。
- 训练场：输入映射加 `move_down`（S/↓）；提示文本加方向键与 236+C / 214+D；状态栏新增“浮空受击（N）/ 空中已受身”。
- 测试：session 204 项（新增 51：方向年龄 23/24 边界、识别消费、19 帧慢速 236、只输方向不起手、5C 浮空状态与 48 帧滞空、取消窗关闭先断连、受身当帧断连+落地恢复、落地保留剩余硬直、浮空中独立招式禁追击与恢复后新段、5A→236C 重浮空、5B→214D 方向收尾）+ smoke 39 项（新增 6：键盘 236+C 派生锁定、浮空/受身状态显示、落地回中立）。全部通过。
- 实现注记：方向数字按“输入帧当时的面向”折算（小键盘标准语义）——前向四分之一圆任意面向可用；反向 214 在面向被移动键翻转的中立状态会翻转面向（issue 01 既定面向模型），在招式执行中输入（取消场景）不受影响。待人工试玩：24 帧方向窗口手感、S 键位置、5C/236C 浮空高度与受身-落地间隔、214D 在 5B 后的输入节奏；试玩后直接改 `GameParams` / `MoveData`。
