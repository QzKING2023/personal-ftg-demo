# 03: 方向派生招式与浮空受身

**What to build:** 玩家可以用独立方向序列触发派生招式并将木桩带入浮空，方向识别和木桩自然受身不会被动作键缓存混淆。

**Blocked by:** 02: 稳定地面路线与输入缓存.

**Status:** ready-for-agent

- [ ] 方向输入拥有独立的默认 24 帧历史窗口，年龄 0–23 有效，过期时不能触发派生招式，也不占用动作键缓存。
- [ ] `236C` 和 `214D` 能被识别、消费方向序列并锁定对应派生招式；A/B/C/D 的逻辑语义在招式数据中独立表达。
- [ ] C 的命中结果能将木桩置于浮空受击状态；浮空后续不依赖隐式普通连接。
- [ ] 木桩浮空受身时立即结束连段，落地后才恢复中立；收尾和自然受身仍分别判定。
- [ ] 测试覆盖方向窗口过期、方向消费、派生锁定、浮空状态、浮空受身和落地恢复。
