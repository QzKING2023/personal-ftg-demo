# 07: Solver 空中接续与有限资源验证

**What to build:** Combo Solver 可以验证空中、jump cancel 和落地接续的合法性，区分真正的循环与只能依赖有限滞空资源完成的一次性路线。

**Blocked by:** 05: 完整空中路线与落地接续; 06: Solver 地面接续验证与循环报告.

**Status:** ready-for-agent

- [ ] Solver 能检查空中姿态、jump cancel 配置、落地接缝和显式落地接续。
- [ ] 完整空中路线的合法接续与运行时结果一致，包含 jB 命中优先于落地的临界帧规则。
- [ ] 有限的木桩滞空资源不会被视为可自动续期；只有真实可重复的有效回边才报告为循环。
- [ ] Solver 能区分 `5A → 236C → Space → jA → jB → jD` 的有限路线和注入的有效无限回边。
- [ ] 测试验证 Solver 不证明未经招式数据配置的空间、中立或碰撞连接，并保持与运行时战斗 seam 的状态边界一致。
