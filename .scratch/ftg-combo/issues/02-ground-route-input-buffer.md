# 02: 稳定地面路线与输入缓存

**What to build:** 玩家可以通过命中确认取消和短暂输入缓存稳定完成 `5A → 5B → 5D` 地面路线，并看到递减伤害和连段状态。

**Blocked by:** 01: 单招式逐帧结算与训练场接入.

**Status:** ready-for-agent

- [ ] `5A → 5B → 5D` 在训练场中形成稳定地面路线；每次后续招式都需要前一招的命中确认取消资格。
- [ ] 动作键使用单槽缓存，年龄 0–5 有效、第 6 帧过期，最新输入覆盖旧输入，并且只在命中确认取消阶段消费。
- [ ] 取消窗口默认覆盖命中后的 0–8 帧；挥空、过期输入和没有合法取消资格的独立招式不能继续连段。
- [ ] 连段伤害按 `max(0.1, 1 - (命中数 - 1) × 0.1)` 递减；收尾结束路线但不主动清除木桩倒地处理。
- [ ] 训练场显示连段命中数和木桩当前状态；测试覆盖缓存年龄边界、最新输入覆盖、挥空不消费和地面路线。
