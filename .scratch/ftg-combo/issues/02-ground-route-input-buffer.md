# 02: 稳定地面路线与输入缓存

**What to build:** 玩家可以通过命中确认取消和短暂输入缓存稳定完成 `5A → 5B → 5D` 地面路线，并看到递减伤害和连段状态。

**Blocked by:** 01: 单招式逐帧结算与训练场接入.

**Status:** ready-for-human

- [x] `5A → 5B → 5D` 在训练场中形成稳定地面路线；每次后续招式都需要前一招的命中确认取消资格。
- [x] 动作键使用单槽缓存，年龄 0–5 有效、第 6 帧过期，最新输入覆盖旧输入，并且只在命中确认取消阶段消费。
- [x] 取消窗口默认覆盖命中后的 0–8 帧；挥空、过期输入和没有合法取消资格的独立招式不能继续连段。
- [x] 连段伤害按 `max(0.1, 1 - (命中数 - 1) × 0.1)` 递减；收尾结束路线但不主动清除木桩倒地处理。
- [x] 训练场显示连段命中数和木桩当前状态；测试覆盖缓存年龄边界、最新输入覆盖、挥空不消费和地面路线。

## Comments

**2026-09-13 实现完成（agent）：**

- `CombatSession` 补齐管线第 5/6 阶段：取消判定开放当前招式配置的取消目标（需已命中确认、木桩仍可追击、命中后第 0–8 帧含两端），消费缓存在空闲时起手独立招式、命中确认窗口内转入下一招。连段结束新增 `COMBO_ENDED` 事件（原因：收尾/取消窗口关闭/招式收招/木桩自然受身）。
- 动作键单槽缓存：输入帧按姿态锁定招式 id（地面 `5X`、空中 `jX`），最新输入覆盖旧输入，年龄 0–5 有效、第 6 帧先过期（过期发生在帧输入阶段，先于当帧命中判定）。Space 不占缓存。
