# 06: Solver 地面接续验证与循环报告

**What to build:** 设计者可以用开发期 Combo Solver 检查基础地面路线的合法接续和有效循环，并得到可读的验证结果，而不改变运行时战斗。方向派生和空中接续由 07 覆盖。

**Blocked by:** 02: 稳定地面路线与输入缓存.

**Status:** ready-for-agent

- [ ] Solver 使用与运行时一致的招式数据，生成 5A/5B/5D 基础地面招式的确定性接续图和可读路径。
- [ ] 接续检查考虑前摇、等待时间、取消窗口、木桩硬直和地面姿态。
- [ ] 有效的地面回边会被报告为循环；等待超时、取消窗口不满足或姿态不符的回边不会被误报。
- [ ] Solver 运行不会修改运行时战斗状态，也不会通过全局最大命中数或总时长限制掩盖循环。
- [ ] 测试包含正常 `5A → 5B → 5D` 路线、注入的有效回边和无效回边，并验证报告内容。
