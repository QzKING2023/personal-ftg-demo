# 05: 完整空中路线与落地接续

**What to build:** 玩家可以完成完整浮空/空中路线，并在临界落地帧按显式规则完成 jB 到 5D 的落地接续。

**Blocked by:** 04: jump cancel 与首次空中追击.

**Status:** ready-for-human

- [x] 训练场中可跑通 `5A → 236C → Space → jA → jB → jD`，并显示每次命中、当前姿态和木桩状态。
- [x] jB 的 D → 5D 只在招式明确配置的落地接续条件下成立；落地不会自动授予普通取消资格。
- [x] 同一物理帧命中和落地同时发生时，先用命中刷新木桩硬直，再处理落地，最后判断取消和消费缓存。
- [x] 空中受身、落地恢复中立、空中收尾和倒地处理之间的状态转换可观察，且连段不会在自然受身后继续增长。
- [x] 测试覆盖完整空中路线、同帧命中优先落地、落地接续、空中收尾和自然受身断连。

## Comments

**2026-09-13 实现完成（agent）：**

- 新招式（默认表）：jA 补上 `cancel_targets=["jB"]`；新增 jB（空中连接，4/6/12、伤害 12、击退 80——刻意调低保证 jD 追得上，`cancel_targets=["jD"]`、`landing_cancel_targets=["5D"]`）与 jD（空中收尾，4/7/14、伤害 20、击退 320、`is_finisher`）；jB/jD 均为普通命中（GROUND_HITSTUN，复用"普通命中只在地面附带击飞"，追击不刷新木桩滞空）。
- 落地接续（`MoveData.landing_cancel_targets`）：唯一在招式数据中显式配置的空中 → 地面接缝。运动阶段记录 `_player_just_landed`；取消阶段在落地帧为空中招式额外开放落地接续目标（与动作键取消共用命中确认 + 0–8 帧窗口 + 木桩可追击判定）；消费阶段把缓存的动作键按地面姿态重解析（空中输入的 D 已按姿态锁定为 jD，落地帧重解析为 5D），仅当结果在开放目标内才按合法接续起手。落地帧之后该接缝关闭，落地不授予任何普通取消资格（jA 落地时缓存的 D 直接作废，测试覆盖）。
- 同帧结算顺序（验收 3）：既有管线本身保证"命中判定/受击应用（第 2–3 阶段）→ 运动/落地/自然受身（第 4 阶段）→ 取消判定（第 5）→ 消费缓存（第 6）"。临界测试把木桩硬直预置为 1 帧、jB 命中与玩家落地同帧、D 已缓存：命中先把硬直刷新为 12（当帧不消耗新硬直），落地随后处理，落地接续在第 5–6 阶段把 D 消费为 5D；该帧只产生一个 HIT 事件，连段未被硬直归零打断。
- 空中招式落地清理：消费阶段末尾，仍滞留地面姿态的空中招式作废（空中路线不因落地延续，空中招式落地后不能继续用判定帧命中或取消），连段以 MOVE_RECOVERED（收招未接续）结束；木桩受击处理不受影响。自然受身断连与落地清理共用 `_end_combo` 的活跃守卫，不会出现第二次连段结束事件。
- 顺带修正：`_clear_current_move()` 现在把 `player_phase` 一并归位 NEUTRAL（此前依赖调用方各自设置，落地清理路径会让 phase 滞留在 RECOVERY）。
- 物理细节（测试期望由此确定）：对已被普通命中微浮起的木桩再打浮空招式时，起跳帧当帧即加重力（浮空滞空比从地面起跳少 1 帧落地）；普通命中打在地面木桩上附带向上击飞 110px/s（微浮）——临界测试中 jB 命中落地旁的地面木桩会把它重新微浮约 10 帧再落地倒地。
- 训练场：无需改动即满足验收 1——状态栏已显示每次命中（连段计数/伤害）、玩家姿态（地面/空中）与木桩状态（中立/地面受击/浮空受击/空中已受身）。
