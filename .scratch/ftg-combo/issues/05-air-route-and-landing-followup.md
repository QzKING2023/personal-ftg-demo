# 05: 完整空中路线与落地接续

**What to build:** 玩家可以完成完整浮空/空中路线，并在临界落地帧按显式规则完成 jB 到 5D 的落地接续。

**Blocked by:** 04: jump cancel 与首次空中追击.

**Status:** ready-for-agent

- [ ] 训练场中可跑通 `5A → 236C → Space → jA → jB → jD`，并显示每次命中、当前姿态和木桩状态。
- [ ] jB 的 D → 5D 只在招式明确配置的落地接续条件下成立；落地不会自动授予普通取消资格。
- [ ] 同一物理帧命中和落地同时发生时，先用命中刷新木桩硬直，再处理落地，最后判断取消和消费缓存。
- [ ] 空中受身、落地恢复中立、空中收尾和倒地处理之间的状态转换可观察，且连段不会在自然受身后继续增长。
- [ ] 测试覆盖完整空中路线、同帧命中优先落地、落地接续、空中收尾和自然受身断连。
