# 06: 普通投与拆投

**What to build:** 玩家在地面站立自由行动且处于投距内时同帧按 B+C 执行普通投，并能在规定窗口内拆投；不满足状态或距离时输入失败且不会回退成普通拳脚。

**Blocked by:** 05: 蹲下与站防/蹲防/空防

**Status:** ready-for-agent

- [ ] 同帧 B+C 组合优先于单键 D>C>B>A 选择，并在投距内启动普通投；面向决定投向，不要求额外 4/6 方向。
- [ ] 普通投 startup 固定为 5f，拆投窗口从首个 startup 帧开始并在投发生后延续约 10f；窗口内的有效拆投输入阻止投结果并产生可观察事件。
- [ ] 蹲下、pre-jump、空中、招式阶段、受击硬直和任何落地恢复中，B+C 不执行普通投。
- [ ] 投距外输入失败，不启动普通投，也不回退为普通拳脚或其他单键招式；失败原因可在诊断/事件中区分。
- [ ] 训练场真实键盘路径和 CombatSession 逐帧测试覆盖成功投、距离失败、禁用状态和拆投边界。
