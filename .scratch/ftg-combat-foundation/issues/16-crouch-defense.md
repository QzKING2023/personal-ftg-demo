# 16: 蹲下与站防、蹲防、空防

**What to build:** 玩家用相对方向进入蹲下、站防、蹲防和空防，并用木桩确定性攻击观察 high/mid/low/overhead/air 属性矩阵及各阶段限制。

**Blocked by:** 15: 普通跳、jump cancel 与落地恢复

**Status:** ready-for-human

- [x] 地面自由行动时 1/2/3 当帧进入蹲下并保留水平分量；受限阶段不会被下方向强行改姿态。
- [x] 地面 4 为站防、1 为蹲防；真正离地后 4/1 均为空防，pre-jump 不新进入防御。
- [x] high、mid、low、overhead 与正交 air 属性按显式数据判定；空防默认可挡 air。
- [x] 防御硬直、Hitstop 和木桩反馈可重复观察；落地首帧不可防御，空跳第 2、3 帧可防御，空技恢复全程不可防御。

## Comments

**2026-09-16 实现验收记录（agent）**

- 蹲下与防御姿态（`combat_session.gd`）：`GuardPosture` 枚举（NONE/站防/蹲防/空防）+ `player_crouching` 可观测量。姿态在输入阶段解析（先于命中判定，当帧进入的蹲防参与同帧判定）：地面自由行动 1/2/3 当帧蹲下、1/2/3 的水平分量照常保留（蹲姿行走与站立同速，规格未定义独立蹲行速度）；4 站防且保留后退行走、1 蹲防、真正离地后（离地当帧之后一帧起）4/1 均为空防且 1 的下方向不成蹲。姿态门 `_posture_reeval_open()`：出招、受击/防御硬直、pre-jump、空技落地恢复冻结；空跳落地恢复第 2、3 帧开放（与独立起手门同一口径，输入阶段读到含当帧的恢复倒计时故以 >1 判受限，与消费阶段起手门时序一致）；出招/起跳消费与落地当帧统一经 `_clear_posture()` 清空姿态（落地首帧钳掉空中姿态）。
- 木桩确定性攻击：`FrameInput.dummy_move_request`（招式表打击 id；训练场不设置，测试/验证驱动属性矩阵）。请求在输入阶段被木桩空闲（中立+落地+无进行中招式）时接受，起始帧记 0、运动阶段同帧推进为第 1 帧——请求帧即 F1，判定最早出现在请求 + startup 帧（与玩家消费起手帧序同一口径）；其余状态静默忽略。`dummy_move_id`/`dummy_phase`/`dummy_attack_rect()` 可观察；招式帧在运动阶段推进（停顿冻结）；木桩被玩家命中时攻击被打断（本帧已捕获的连接仍按互换命中结算，同帧互换只报一次 HITSTOP_STARTED）。
- 属性矩阵 `_blocks_attack()`：站防挡 high/mid/overhead、漏 low；蹲防挡 high/mid/low、漏 overhead；空防默认挡带 `air` 的打击，纯地面属性不在空防默认域（CONTEXT「空防默认可挡带 air 的打击」的字面域），未来例外需显式声明；无姿态不挡。判定全部来自招式数据的 `attack_attribute` + 正交 `air_attack`。受击硬直中被打破的防御不提供保护（硬直期间一律不挡；姿态可观测量冻结在原值只是「不改姿态」）。
- 防御命中：`BLOCKED` 事件 + 防御硬直 + Hitstop（8f，冻结双方：硬直不倒数、木桩招式不推进）。防御硬直时长取打击数据 `hitstun_frames`（规格未定义独立防御硬直参数，选数据驱动口径，真人试玩可随资源调整）；硬直期间姿态冻结 = 连防语义（硬直中被同一姿态再次挡下，无需重新按住 4），出招/起跳/移动全部锁定，面向同受击硬直口径冻结（规格未列防御硬直，按受限阶段类比处理）。
- 未防御命中：`PLAYER_HIT` 事件 + 玩家受击硬直（= 打击 hitstun，滞空暂停消耗与木桩地面硬直同口径）+ 水平击退 + Hitstop；进行中的招式被打断（连段以收招未接续结束）。玩家无生命值系统，打击数据对玩家只作用硬直与位移。受击硬直中不蹲、不防、不出招、不移动输入。
- 边界说明：落地帧的命中判定先于落地结算（spec「同帧命中与落地时先完成命中和受击，再处理落地」），该帧命中检测时玩家仍算空中、按空防判定——落地恢复首帧不可防御以运动阶段的姿态钳制执行（钳后可观测量为 NONE）。
- 训练场：蹲下以纵向压扁（`PLAYER_CROUCH_SCALE`）、防御以整体变色（`PLAYER_GUARD_COLOR`）呈现；诊断行新增 防御列（站防/蹲防/空防·防僵N/受击N）；键位提示补防御说明。木桩在实机仍不主动攻击（无自主决策），木桩攻击仅经逐帧请求驱动。
- 验证：test_combat_session 533 项全绿（新增当帧蹲下与水平分量/三姿态与 pre-jump 离地当帧不防御/木桩攻击生命周期与被打断/属性矩阵全格/防御硬直与停顿冻结与可重复/未防御命中锁定/受限阶段不蹲/落地防御门三段/连防保持姿态/防御被打破后硬直不设防等 ~82 项断言）；test_combo_solver 112 全绿；test_smoke 95 全绿（新增真实键盘路径蹲下/站防/蹲防呈现与诊断行）；test_move_table 129 全绿；diagnose_inputs 全绿；主场景无头运行无错误。
- 范围说明：拆投与 B+C 组合（issue 17）、66/44（issue 18）未提前实现——落地恢复对拆投的限制仅以结构方式不绕过（无任何路径可在受限恢复期执行投）；玩家生命值/玩家倒地不在本票与规格范围内。
