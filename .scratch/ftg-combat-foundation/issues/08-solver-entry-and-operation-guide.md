# 08: Solver 入口与操作说明

**What to build:** 设计者可以通过明确的开发期入口调用 Combo Solver，从默认地面中立或显式中间状态开始分析共享招式表，并得到稳定、可回放且带起始条件的结果和操作说明。

**Blocked by:** 01: 共享本地招式数据与非法表拒绝

**Status:** ready-for-agent

- [ ] Solver 入口接受共享招式资源表、可选起始战斗状态和搜索选项；未提供状态时使用地面中立、空缓存/方向历史、地面中立木桩和固定探针接触位。
- [ ] 默认入口分别验证左右面向；首招只从当前可执行的地面招式枚举，空中招式不能直接起手；中间状态必须由调用方显式提供。
- [ ] 输出包含稳定排序的候选边、配置缺口、逐帧可回放输入、命中帧/命中数/总伤害、失败断点与原因以及起始状态说明。
- [ ] 操作说明能把 Solver 输出转换为训练场真实方向键、Space 和动作键输入，注明面向、站位和等待帧。
- [ ] Solver 使用私有一次性探针，不修改活动 CombatSession；同一招式资源的修改与非法加载结果在训练场和 Solver 中保持一致。
