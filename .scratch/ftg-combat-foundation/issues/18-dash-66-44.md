# 18: 66 前冲与 44 后撤

**What to build:** 玩家在地面自由行动中输入 66 前冲或 44 后撤，第二个独立同向方向段到来时启动；持续按住不会重复触发。

**Blocked by:** 15: 普通跳、jump cancel 与落地恢复

**Status:** ready-for-agent

- [ ] 66/44 要求两个同向方向段，中间至少一个逻辑中立帧；第二段到来时启动对应动作并持续 12f。
- [ ] 持续按住不生成重复冲刺；方向段、启动和结束状态可由事件/诊断观察。
- [ ] 仅地面自由行动识别，出招、受击、pre-jump、空中和受限落地恢复中不触发。
- [ ] 启动时锁定面向，左右面向下输入镜像一致；high-jump 与二段跳保持范围外。
