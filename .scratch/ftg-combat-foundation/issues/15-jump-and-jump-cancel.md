# 15: 普通跳、jump cancel 与落地恢复

**What to build:** 玩家经历可观察的普通跳阶段，并在命中确认且配置允许时用 Space 进入一次 jump cancel，接上指定空中招式；落地恢复限制统一生效。

**Blocked by:** 12: 面向锁定、空中动量与方向派生; 14: Hitstop、输入缓存与命中确认取消

**Status:** ready-for-agent

- [x] 普通跳包含 4f pre-jump、38f 空中阶段和 3f 基础落地恢复；pre-jump 按地面姿态，离地首帧按空中姿态解析。
- [ ] pre-jump 只允许显式配置的地面必杀取消；普通拳脚、投、防御和再次跳跃不可用。
- [x] jump cancel 同时要求配置目标、实际命中、木桩可追击和取消窗口开放；Space 不触发二段跳且不重置原窗口。
- [x] 停顿内 jump 保留按下帧世界跳向；jump 与攻击竞争时较新请求优先，同帧攻击优先，每帧最多启动一个。
- [x] 任何落地恢复首帧不可攻击、防御、蹲下、拆投或取消；空技启动后全恢复期不可取消，空跳第 2、3 帧例外可观察。

## Comments

**2026-09-16 实现验收记录（agent）**

- 跳跃分期（`combat_session.gd`）：`GameParams` 新增 `PLAYER_PREJUMP_FRAMES=4`、`PLAYER_LANDING_RECOVERY_BASE_FRAMES=3`、`PLAYER_AIR_ATTACK_LANDING_PENALTY_FRAMES=1`，`PLAYER_JUMP_AIRTIME_FRAMES` 40→38。Space 请求在消费阶段被接受（接受帧即准备第 1 帧，公开可观察 `player_prejump_left` 4/3/2/1）；运动阶段正常帧倒数，倒数到 0 当帧离地（当帧不加重力，滞空恰 38f）；`_current_stance()` 离地当帧即按空中姿态解析动作键（spec「下一个正常帧离地并按空中姿态解析」，有专项测试）；落地帧起 `player_landing_recovery_left` 倒数基础 3f。整周期 45f 有专项断言。
- 跳跃输入槽：独立单槽记录 Space 按下（Space+下不触发跳跃），冻结按下帧世界水平跳向与按下物理帧；最新按下覆盖、按住不重复；年龄按正常帧计（停顿中暂停、恢复首帧年龄 0、年龄 6 在消费前过期，`debug_snapshot` 暴露 `jump_slot_direction/jump_slot_age`）。消费前松键/反向/面向变化不重写请求——准备期移动按冻结方向（含离地当帧），反向输入不改变起跳横向速度；原始 8 请求（冻结方向 0）在准备内仍可用当前输入改成斜跳，不重置准备计时；离地后方向锁定。
- 竞争仲裁：`_buffer_action_candidate()` 是动作缓存可消费判据的唯一来源；与跳跃槽同帧合法时比较原始请求物理帧——较新者优先、同帧攻击优先，每帧最多启动一个新动作，未选中的槽保留原年龄后续重查（专项测试三组：jump 新/attack 新/同帧）。
- pre-jump 锁定：`_independent_start_allowed()` 在准备期一律拒绝缓存独立起手。范围说明：spec 的可选字段清单未定义 pre-jump 取消目标的配置位（MoveData 无对应字段），因此没有任何"显式配置的地面必杀取消"可存在——按 spec 120「未声明的连接不发生」，全部输入只记录不消费；本条验收的否定面（普通拳脚、方向必杀、再次跳跃不可用；准备内按下保持地面解析、不跨姿态重解释）全部有专项测试。正配置位留待数据模型扩展时落地。
- 落地恢复锁定：首帧（落地当帧）新按下的动作键只保留原始输入、不进入可执行缓存（落地时清除当帧新鲜按下；解释为统一的首帧锁——空跳为 spec 明文，空技落地同口径且空中解析的按键本就无法地面起手）；空跳恢复第 2、3 帧可取消为合法攻击（按下即地面解析当帧起手）；启动过空中招式（挥空同样）基础+额外恢复全程不可取消，缓存保留原龄、恢复结束才起手。空中招式 startup 启动即 +1f（每跳一次），资源 `extra_landing_recovery_frames` 显式叠加；延长不改变空中阶段（落地帧与空跳一致有专项对照）。
- jump cancel：配置 + 实际命中 + 取消窗口 + 可追击同时成立才消费，转入普通 4f 准备（不重置原取消窗口或跳跃计时）；空中 Space 一律无效（无二段跳）。配置的落地接续仍在落地当帧消费（issue 12/14 既有接缝，spec 120「落地接续必须显式列为目标」；与 133 条首帧锁的张力在此记录：接缝走取消路径，属显式配置例外）。
