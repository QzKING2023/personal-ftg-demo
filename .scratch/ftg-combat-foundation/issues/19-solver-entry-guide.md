# 19: Combo Solver 入口与操作说明

**What to build:** 设计者可以从默认地面中立或显式中间状态调用 Combo Solver，读取共享招式表并得到稳定、可回放且带起始条件的结果和操作说明。

**Blocked by:** 11: 共享本地招式资源与非法表拒绝

**Status:** ready-for-human

- [x] 入口接受共享资源表、可选起始战斗状态和搜索选项；缺省状态为地面中立、空缓存/方向历史、地面中立木桩和固定接触位。
- [x] 默认分别验证左右面向；首招只枚举当前可执行的地面招式，空中招式不能直接起手；中间状态须显式提供。
- [x] 输出稳定排序的候选、逐帧回放输入、命中帧/命中数/总伤害、失败断点与原因及起始状态说明。
- [x] 操作说明转换为真实方向键、Space 和动作键，并注明面向、站位和等待帧。
- [x] Solver 使用一次性探针且不修改活动 CombatSession；资源变化与非法加载结果同训练场一致。

## Comments

**2026-09-17 实现验收记录（agent）**

- 正式入口 `ComboSolver.solve(options)`（`scripts/combat/combo_solver.gd`）：`SolverOptions` 接受共享 manifest（默认 `data/move_manifest.tres`，显式注入表优先）、可选 `SolverStartState`（显式中间状态）与验证面向列表（默认 `[1, -1]` 左右分别验证）。旧入口 `analyze()/analyze_manifest()` 原样保留（表序枚举、单面向），旧回归基线（ftg-combo 06+07 测试）不动、全绿。
- 缺省起始状态：地面中立、空输入缓存/方向历史、地面中立木桩、固定探针接触位 70px；报告新增「起始状态」节如实描述（含"几何接触是假设，不构成空间证明"）。
- 左右面向：每个面向用独立 Solver 实例完整分析（探针面向镜像、方向喂入按面向折算），报告以相对方向签名镜像对拍——签名覆盖接续边时序、落地接续边的 align 窗口与回放样本、路线逐帧输入与断链注记、循环结论；一致记注、不一致列出差异节并置 `mirror_consistent=false`；`verified_facings` 可观察。
- 首招候选：起始姿态下当前可执行、可用本 Solver 输入表达（单键 + 方向喂入）起手的打击招式，稳定 id 序输出；默认地面起始不含空中招式与 BC 投（投为 B+C 组合输入，报告注记说明）；显式空中起始切换为 jA/jB/jD，路线起点同步按起始姿态枚举。显式空中起始以确定性探针序（Space 垂直跳 + 4f 起跳准备 + N 空中帧）带入，`air_frames` 越界（<0 或 ≥38 滞空）整份拒绝并给出修正方向，不静默钳制成别的起始条件。
- 输出：solve() 的接续边按 from→to→kind、路线按标签稳定排序（排序键无并列，确定性成立）；报告保留逐帧回放输入（ScheduledInput 表）、命中帧/命中数/总伤害、排除边与断链路线的失败原因，并新增起始状态说明。
- 操作说明：报告新增按验证面向分节的真实键位回放指引——前/后/下按面向折算为 D/→、A/←、S/↓（左面向下前 = A/←、后 = D/→，箭头随物理键互换），Space 与 U/I/K/J=A/B/C/D，帧间空档标注「等 N 帧」，分节头注明面向、站位（中心间距 70px）与起始条件；空中起始分节另附 Space 探针序说明。键位映射 `ACTION_PHYSICAL_KEYS` 与训练场 main.gd 一致（测试断言两处不漂移）。
- 一次性探针与共享资源一致：所有验证仍走私有 CombatSession（测试对活动会话做全字段快照对拍）；非法表经 solve() 拒绝且 `refusal_reason` 与 MoveTable 首条错误（即训练场显示的同一原因）完全一致；修改注入表 startup 后 solve 的时序报告同步变化（issue 11 双端一致在正式入口上的回归）。
- 范围说明：显式空中起始的落地接缝不宣称有效（排除原因注明临界对齐搜索依赖 jump cancel 进入的空中段，属 issue 20）；timing-valid/spatial-valid 分层是 issue 22、循环状态去重证明是 issue 21、回放联合验收是 issue 23，均未提前实现。空中起始复用既有 06/07 上下文机制、仅参数化起始姿态（含新增 `_context_via_landing` 上下文增长使配置了落地接续链的地面招式可达），未新增枚举维度。
- 验证：新增 tests/test_solver_entry.gd（入口契约、双面向镜像、首招候选、真实键位操作说明、稳定排序、确定性、探针隔离、非法表同因拒绝、资源变化同步、键位映射一致、显式空中起始路线验证与越界拒绝）；test_combat_session、test_combo_solver（112）、test_move_table、test_smoke、diagnose_inputs 全绿；主场景无头 300 帧无错误。
