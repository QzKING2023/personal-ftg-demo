# 19: Combo Solver 入口与操作说明

**What to build:** 设计者可以从默认地面中立或显式中间状态调用 Combo Solver，读取共享招式表并得到稳定、可回放且带起始条件的结果和操作说明。

**Blocked by:** 11: 共享本地招式资源与非法表拒绝

**Status:** ready-for-agent

- [ ] 入口接受共享资源表、可选起始战斗状态和搜索选项；缺省状态为地面中立、空缓存/方向历史、地面中立木桩和固定接触位。
- [ ] 默认分别验证左右面向；首招只枚举当前可执行的地面招式，空中招式不能直接起手；中间状态须显式提供。
- [ ] 输出稳定排序的候选、逐帧回放输入、命中帧/命中数/总伤害、失败断点与原因及起始状态说明。
- [ ] 操作说明转换为真实方向键、Space 和动作键，并注明面向、站位和等待帧。
- [ ] Solver 使用一次性探针且不修改活动 CombatSession；资源变化与非法加载结果同训练场一致。
