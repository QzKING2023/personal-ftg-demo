# 02: 面向锁定、空中动量与方向派生

**What to build:** 玩家在训练场中按相对面向练习地面与空中招式：地面自由行动时面向木桩，后退不翻面；左右面向都能稳定触发 236/214 派生；跳起后普通空中运动保持起跳动量和面向，空中方向序列仍能按锁定面向解析。

**Blocked by:** 01: 共享本地招式数据与非法表拒绝

**Status:** ready-for-agent

- [ ] 地面中立、移动、蹲下和后退时，玩家每帧按规则面向木桩；后退不会翻面，横向重合时保持当前面向，出招/受击/空中阶段保持进入阶段时的面向，落地完成后重新面向。
- [ ] 左右面向下使用同一套相对方向输入，236C 与 214D 均能在正确动作键按下时识别并执行；地面中立和后退后的方向历史不再因移动翻转而失败。
- [ ] 跳跃后松开水平键或按反方向，普通空中速度向量和面向保持起跳值；主动方向输入不会改变普通空中运动，越过木桩也不自动转身。
- [ ] 空中方向历史按锁定面向折算，配置的空中方向派生可在真实训练场输入路径中识别；未识别、识别但不可接续和成功出招但未命中可区分。
- [ ] 阶段 1 已完成的 HUD、诊断可观察性和普通空中动量回归保持通过，本 issue 不重复实施这些已完成修复。
