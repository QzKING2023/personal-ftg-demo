# 11: 共享本地招式资源与非法表拒绝

**What to build:** 设计者编辑一份类型化本地招式资源后，训练场与 Combo Solver 使用同一份已校验数据；修改同一招式的 startup、伤害、属性或取消关系会在两处产生一致的可观察变化，非法表会整体拒绝。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 训练场和 Solver 从同一份 manifest 读取稳定 id、姿态、输入绑定、帧窗口、优先级和效果。
- [ ] 打击招式或投技缺少必填字段时，整张表拒绝加载；错误指出来源、招式 id、字段和原因。
- [ ] 类型错误、负帧数、未知枚举、非法方向谓词、矛盾字段及非法跨招式引用均拒绝，且不回退旧 GameParams。
- [ ] 修改合法资源后，训练场行为和 Solver 报告同步变化；非法修改在两处显示同一拒绝原因。
