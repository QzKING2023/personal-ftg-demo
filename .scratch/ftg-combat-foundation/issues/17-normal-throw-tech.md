# 17: 普通投、投距失败与拆投

**What to build:** 玩家在地面站立自由行动且处于投距内时输入 B+C 执行普通投，并能在规定窗口内拆投；不满足状态或距离时输入失败且不回退拳脚。

**Blocked by:** 16: 蹲下与站防、蹲防、空防

**Status:** ready-for-agent

- [ ] B+C 在 ≤3f 组合容差内且两键仍按住时覆盖单键选择，投距内启动普通投；面向决定投向。
- [ ] 普通投 startup 固定 5f，拆投窗口从首个 startup 帧开始并在投发生后延续 10f；有效拆投阻止投结果并产生日志/事件。
- [ ] 蹲下、pre-jump、空中、招式阶段、受击硬直和落地恢复中不执行普通投。
- [ ] 投距外失败，不启动普通投，也不回退普通拳脚；失败原因可观察。
- [ ] 真实键盘路径与逐帧 CombatSession 测试覆盖成功、距离失败、禁用状态和拆投边界。
