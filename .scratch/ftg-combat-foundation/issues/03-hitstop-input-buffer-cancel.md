# 03: Hitstop、输入缓存与命中确认取消

**What to build:** 玩家命中木桩后经历固定 Hitstop，并能在停顿中输入下一招；恢复后的首个正常帧按缓存和取消资格决定是否接续。挥空、过期缓存或关闭的取消窗口不会伪装成连段。

**Blocked by:** 01: 共享本地招式数据与非法表拒绝

**Status:** ready-for-agent

- [ ] 命中帧完成命中与受击应用后，双方从后续物理帧起冻结规定的 Hitstop 帧数；位置、速度、招式阶段、硬直、落地和受身计时在停顿中不推进，物理帧号仍递增。
- [ ] Hitstop 中的物理键、方向历史和动作键按下/按住/松开事件仍被记录；缓存、方向窗口和取消窗口年龄在停顿中暂停，恢复后的首个正常帧才可消费。
- [ ] 动作键单槽缓存遵守最新输入覆盖旧输入及年龄边界；命中同帧记录且合法的输入可在该帧命中后的取消阶段消费，过期输入不会执行。
- [ ] 命中确认取消只在实际命中、木桩仍可追击、目标已配置且取消年龄有效时成立；挥空永不获得取消资格。
- [ ] 训练场诊断和 CombatEvent 能显示 Hitstop 边界、缓存年龄、取消资格和实际消费结果，并覆盖窗口末帧/首个恢复帧。
