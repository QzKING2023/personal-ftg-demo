# D 系位移先参与命中计划，再提交正式位置

状态：accepted（阶段 1 设计决定，尚未实现）

D 系需要在命中帧按攻击姿态和实际位移判断穿越。采用命中判定前计算本帧计划位移、以计划攻击姿态判定接触、受击应用后在运动阶段提交正式位置的方式，使当帧位移能参与攻击判定，同时保留集中结算及命中先于落地的顺序。

这细化了 [ADR-0002](0002-natural-recovery-combo-rules.md) 的几何取值时点：命中阶段可以读取计划运动结果，正式位置仍在运动阶段改变；不能将“保留阶段顺序”理解为“所有攻击仍只看帧首静态位置”。跨身命中在本帧结算攻击和位移，下一帧才使用新面向；本招轨迹方向在启动时锁定，当前面向和方向候选按阶段 1 的三层语义更新。

运行时与 Solver 必须复用同一计划及提交规则，不能各自模拟一套先移动或先命中的行为。墙和身体约束应用后的实际终点决定是否真实穿过，计划终点本身不是成功换边证据。实际命中可开放本次位移的身体穿越，被防或挥空时位移截在原侧；被防、挥空和墙截断不得触发换边。

本决定仅固定计划与提交的结算边界；身体穿越许可、路径中途攻击覆盖和同帧受击打断细节仍在 [阶段 1 决策](../../.scratch/ftg-character-implementation/decisions.md) 中继续收敛。
