# 玩家角色设计

> 更新：2026-09-23  
> 状态：本文保留角色研究背景、外形和早期战斗提案；逐招职责、取消矩阵和连段状态以[角色招式完整设计基线](player-character-move-design.md)为准。  
> 交付范围：外形、战斗方式、招式与必杀技；本轮不修改代码、招式资源或运行参数。

## 1. 设计依据与目标

研究依据为[武器型刺客角色研究](weapon-assassin-character-research.md)。该研究提供参照和差异轴，不直接指定本角色的武器、外形或机制。

本角色需要将刺客式的时机选择、短促执行和追击／退场选择，落实为玩家能操作、能辨认失败原因的战斗动作。武器应持续出现在基本攻击、击飞、空中追击和必杀动作中，形成一致的动作语言。

本轮用户已确认：**沿用浮空追击与空中连段的主要体验，再设计刺客特色。** 地面短路线、接近手段和角色机制围绕这一主轴组织，不另设与之竞争的主要体验。

当前体验是单玩家角色与木桩的短流程展示。角色最终需要具有合理的攻防关系，但静态木桩上的连段展示不能证明中立博弈、压制或撤离在真实对战中成立。

## 2. 继承的设计基线

依据：[角色招式定位与取消规则](../.scratch/ftg-move-design/design-decisions.md)、[领域术语](../CONTEXT.md)、[当前招式数据说明](move-data.md)。本节区分已接受设计与现有实现；旧资源的用途不覆盖后续设计决定。

| 项目 | 已接受设计 | 对本角色设计的约束 |
| --- | --- | --- |
| 主体验 | 浮空追击与空中连段 | 必杀和特色机制需要明确它们如何帮助切入、追击或收尾 |
| 专用击飞入口 | 6A，地面可直接输入，也可由普通链进入 | 不把 5C 或旧 236C 的浮空资料当作角色最终职责 |
| 地面普通链 | 5A → 5B → 5C → 5D；另有 5B → 5D | 5D 属于普通地面 gatling 招式，其具体动作与命中结果需要本轮设计 |
| 击飞分支 | 5A、5B、5C 均可链到 6A | 取消许可不保证任意站位都能实际接上 |
| 6A 出口 | 命中确认后 jump cancel → jA；保留配置其他链式／必杀出口的能力 | 其他具体出口待设计，不将未配置误写为禁止扩展 |
| 空中骨架 | jA → jB → jD | 动作、节奏和收尾效果待角色设计；新增或修改路线需要明确记录 |
| 链式／必杀取消 | 命中或被防可取得资格，挥空不成立；逐招列出目标 | 被防后的退场或派生不能默认为无风险；新机制不能暗中加入挥空取消 |
| 跳跃取消 | 需要实际命中确认、合法窗口和可追击目标 | 被防不能自动转为空中追击 |
| 236C | 退出专用击飞职责，作为必杀重设计 | 输入是已有占位，不等于新动作已经决定 |
| 214D | 普通倒地收尾方向 | 倒地定时自然恢复，进入倒地即结束当前连段；不默认开放倒地追击 |
| 空中与落地 | 空中资源有限；空技落地完整承担恢复 | 不默许二段跳、自动延长滞空或落地首帧取消 |
| 连段结束 | 遵循自然受身／恢复及合法接续条件 | 不用全局命中数上限掩盖无限循环；收尾不强制清空受击状态 |

当前实现仍有设计同步缺口，尤其是链式／必杀取消分层及部分招式职责。本文之后提出的新能力也须分别标记为现有能力、待同步设计或新增能力，不能称为已经可玩。

## 3. 角色概念与外形

已确认核心武器方向：一把普通短刀。角色不依靠开合、双刀协同、投掷库存或武器状态循环建立玩法记忆点；辨识度来自移动、接触时机、出刀位置和收刀节奏。本文统一使用“短刀”作为设计术语；“匕首”只用于描述刀身外观时的自然语言，不作为另一套武器规则。

已确认能力尺度：允许少量真正的影步／瞬移，但只服务于切入与撤离，不作为分身、持续隐身或独立伤害主体。进一步收紧为一组“带位移的招式”：具体输入可以选择无攻击判定的假动作，也可以选择带真正攻击判定的变体。两类变体共用刺客式的位移语言，但不共用相同的风险收益；平衡重点放在起手、攻击出现帧、终点位置和收招后摇。影步与其攻击变体都不默认拥有无敌或自动命中。

已确认外形气质：她外表像一个普通女孩，真实身份却是冷酷的职业执行者。外形不直接穿成传统刺客，而通过日常服装与极少数功能性细节形成反差；真正的身份在出刀握法、眼神变化、重心转换和干净的动作停顿里暴露。

### 3.1 外形提案

- **远景轮廓**：不锁定具体年龄，只使用普通女孩的日常比例，身形轻、肩线自然，不使用长斗篷、兜帽或大面积装甲。站立时像在通勤或等车；进入战斗时只通过前倾、收肩和短刀手的抬起改变轮廓。
- **服装基底**：轻便通勤装：短夹克或针织上衣、短下装或长裤、低调运动鞋。服装看起来可以买到、可以日常穿着，不使用组织徽记或夸张金属装饰。
- **隐藏功能细节**：持刀侧袖口／前臂内侧有一个看似普通的固定结构，只有拔刀、收刀和影步动作才暴露其用途。功能细节只保留这一处主锚点，避免把“普通女孩”重新画成全身战术装备。
- **配色**：日常主色使用米白、灰蓝或柔和中性色；短刀与持刀侧细节使用一小块冷色或暗红色作为动作识别点。颜色不靠全黑制造刺客感。
- **脸与表情**：中立状态保持礼貌、疏离或略显无害的表情；攻击启动瞬间眼神变平、下颌收紧，命中后立即恢复克制。这个变化要短而清楚，不能用夸张怒吼替代冷酷。
- **短刀**：一把普通、实用、易隐藏的短刀，刀身不做魔法发光或收藏品纹样。握法在贴身普通技、影步攻击和收刀间保持一致，玩家能凭刀尖方向认出招式意图。
- **动作节奏**：日常状态有轻微松弛和重心游移；出招时去掉多余摆臂，先稳定身体轴线再出刀；收刀有明确的卡点，形成“普通女孩的外表、执行者的动作纪律”这一反差。
- **声音识别**：拔刀使用短促的机械摩擦声，影步使用鞋底／衣料的快速切声，攻击命中使用干脆的刀刃声。项目当前没有音效实现，这些是未来反馈设计，不是本轮已验证内容。

外形目前锁定“普通女孩外表／冷酷执行者身份”的关系；不说明具体年龄，日常伪装采用轻便通勤装。短刀的隐藏位置和服装具体款式仍需用户选定。

命名、帧数、空间连接和逐招取消边仍留给后续原型轮；它们不改变本轮已经收束的角色概念和战斗主轴。

定稿将覆盖：一句话角色概念、人物身份与性格、远景轮廓、服装与配色、武器结构及携带方式、站姿与移动姿态、攻击与收刀的视觉和声音识别点。

## 4. 战斗方式

### 4.1 核心循环

已确认的主轴是：**切入有效距离 → 地面命中确认 → 6A 击飞 → 跳跃取消 → 空中追击**。

当前工作提案把战斗拆成四个可读阶段，并把“影步假动作 + D 系位移攻击”作为同一套输入语言：

1. **测距**：用走位、跳跃、短刀的近距离普通技和影步威胁，让对手不能只盯住一个接近高度。
2. **接触**：用 5A、5B、5C 的短链确认是否真的碰到对手。接触成功后，玩家决定继续普通链、转入 6A，还是用影步改变位置。
3. **执行**：6A 是明确的击飞按钮。确认命中后 jump cancel 进入 jA → jB → jD；空中段以短促、连续、不断改变身体轴线的刀技为主。连段中的位移、换边和假动作是角色的主要熟练点，目标是形成类似 Seth 的“不断改变接触点”的节奏。
4. **退场或收尾**：地面进攻被防住或距离不对时，使用 236C／214C 假动作换位，或用 D 系位移攻击赌一次接触；本轮进攻完成后用 214D 的击倒收尾重置局面。换位与爆发通过 C 假动作、D 系普通技和 D 系必杀分别表达，每个输入的起手、攻击出现帧和收招后摇必须可读。

这让角色的刺客感来自“何时接触、接触后是否继续、结束后站在哪里”，而不是来自持续隐身或不可读的随机出现。

参考方向不是照搬角色机制：Seth 提供“连段中持续位移、换边和重新接触”的节奏参照；Hazama 的 Oroboros 与 Hibiki Kohaku 的 D 系提供“动作键本身承担位移＋攻击”的语言参照。本角色只吸收这两种清晰关系，仍以现有 FTG Demo 的 6A 击飞、jA → jB → jD 空中骨架、普通倒地和无专用资源为边界。

### 4.2 影步的工作定义

影步招式不产生残影分身，不留下场地物，也不改变武器状态。攻击变体是“长位移突进 + 短刀攻击”，明确没有无敌；它的收益来自穿过或贴近目标，风险来自起手、攻击出现前的可反制窗口、终点位置和挥空后摇。假动作变体没有攻击判定，但同样要承担位移期间和收招期间的风险。

**当前输入提案**：`236C` 是向前穿越的纯假动作，`214C` 是向后脱离的纯假动作；真正的长位移短刀攻击由 D 系普通技和 `214D` 承担。C 假动作与 D 系攻击让玩家在同一套位置语言中选择“骗防／换边”或“真正出刀”，不需要额外资源条。具体帧数、攻击出现时点、终点距离与取消边留到数值调校轮。

为形成类似 Seth 的连续换边感，首版直接让 `jD` 承担空中长位移短刀攻击，不另设 `j236D`。这样空中路线只需要在 jA、jB 后判断是否用 jD 换边收尾，不会同时管理空中普通 D 与空中特殊 D 两套攻击资源。空中纯假动作暂不加入，避免空中同时拥有过多不可读分支。

### 4.3 三种接触结果

| 结果 | 玩家获得的东西 | 主要风险 |
| --- | --- | --- |
| 命中 | 可按普通链继续；确认后可转 6A 并跳跃追击；也可用影步调整下一次位置 | 过早转入 6A 会因距离或硬直不足而断线 |
| 被防 | 仍可按已设计的链式／必杀取消继续压制或退出，但不能取得 jump cancel | 对手有机会在影步终点、长后摇或错误派生时反击 |
| 挥空 | 没有链式／必杀取消资格，回到招式自身的后摇处理 | 短刀距离短；错误接近会承担完整后摇，不能用影步掩盖所有失误 |

这三种结果沿用项目既有取消分层：命中确认服务于击飞与空中追击，链式／必杀取消服务于命中或被防后的继续行动，挥空不自动获得任何一类取消。

### 4.4 角色强项与弱点

**强项**：近距离确认清楚；命中后可稳定进入空中路线；影步能改变双方横向关系；214D 能以击倒结束一轮进攻；动作短、停顿清楚，适合玩家学习节奏。

**弱点**：短刀没有长距离牵制；影步不带无敌，不能代替防御；影步终点可预测；空中路线结束后不能依靠 OTG 继续压倒倒地目标；普通链和 6A 的职责清楚但不覆盖所有距离。

**熟练度分层**：新手先练 5A → 5B → 6A → jA → jB → jD；熟练后再学习 5A → 5B → 5C → 6A、被防后的影步换位、以及将 214D 与位置选择结合。高难度来自判断和路线选择，而不是额外搓出一套武器资源循环。

## 5. 普通招式与指令普通技

以下是逐招设计提案。没有写入帧数、伤害或像素距离；这些属于之后的数值调校和原型验证。接续名称沿用现有设计基线，具体取消字段仍需实现时配置。

### 5.1 地面普通技

| 招式 | 动作与视觉重点 | 战术职责 | 命中／被防／挥空后的设计意图 |
| --- | --- | --- | --- |
| 5A「腕底短刺」 | 刀尖从身体内侧快速探出，另一只手压低对手视线；收刀动作短 | 最快的近距离确认、起手和打断 | 命中或被防进入 5B；命中可转 6A；挥空承担完整短后摇 |
| 5B「肋线穿入」 | 身体前送半步，刀沿肋线水平穿过，前臂与刀形成清楚直线 | 中距离连接，确认后继续主链或切入击飞 | 命中或被防进入 5C、5D 或 6A；挥空不能用影步补救 |
| 5C「肩线断」 | 先收肩再放刀，动作比 5B 慢但轮廓更大 | 地面链的高回报连接点；把距离和击飞选择交给玩家 | 命中或被防进入 5D 或 6A；命中可为未来必杀取消提供稳定入口；挥空风险明显 |
| 5D「穿步回斩」 | 由 5C 的收肩动作直接踏入目标侧，短刀在穿步末端回斩；可在目标近侧或另一侧结束 | D 系地面位移攻击与换边点；普通链收束，但不承担击飞专属职责 | 命中保持地面硬直；被防后结束普通链并暴露后摇；挥空不产生派生 |
| 6A「抬腕挑」 | 非持刀手先拨开路线，短刀从下向上挑起；动作是角色最清楚的“执行开始”标志 | 唯一专用击飞入口；地面中立可直接输入，也可由 5A/5B/5C 命中或被防后的链式规则进入 | 只有实际命中并满足命中确认条件时 jump cancel → jA；被防不能进入空中追击；挥空没有 jump cancel |

5A → 5B → 5C → 5D 是包含 D 系位移攻击的地面线；5A/5B/5C → 6A 是空中主路线的共同入口。普通投 BC 保留为近距离选择，不把投结果当作打击连段入口。

### 5.2 空中普通技

| 招式 | 动作与视觉重点 | 战术职责 | 路线位置 |
| --- | --- | --- | --- |
| jA「落点确认」 | 身体收紧，短刀朝下做小幅刺击；刀尖先出现，动作清楚 | 空中追击的快速入口，帮助玩家确认自己仍在有效距离 | 6A 命中后的 jump cancel 起手；可接 jB |
| jB「交叉横断」 | 以腰为轴转身，短刀从身体外侧横切，刀臂和腿形成交叉轮廓 | 空中连接与位置修正；比 jA 更能维持路线 | jA 后的主要连接；可接 jD |
| jD「坠线收刀」 | 最高点短暂停顿后以长位移向下收刀，身体沿斜线穿过目标；命中反馈最重 | D 系空中位移攻击、换边与收尾；结束连段并把双方距离拉开 | jB 后终点；不通过落地首帧取消继续地面连段，不开放 OTG |

空中路线的动作节拍应是“短刺—横断—停顿—坠落”，让玩家能从声音和停顿判断是否已经进入收尾。jD 的具体命中资料仍须与现有 airborne profile 语义共同验证。

### 5.3 D 系位移普通技

D 系不是一条额外资源系统，而是角色对动作键 D 的统一解释：**用身体位移换取短刀攻击距离，攻击变体没有无敌，命中后按显式路线继续，挥空承担完整后摇**。它让角色在普通链里就拥有移动攻击的记忆点。

| 招式 | 动作与视觉重点 | 战术职责 | 接续与风险 |
| --- | --- | --- | --- |
| 5D「穿步回斩」 | 由 5C 的收肩动作直接踏入目标侧，短刀在穿步末端回斩；可在目标近侧或另一侧结束 | 地面普通链的位移攻击与换边点；5A → 5B → 5C → 5D 的主链终点 | 命中保持地面硬直，不负责击飞；被防后结束普通链并暴露后摇；挥空不能取消 |
| 6D「直线追入」 | 从地面自由行动向前跨入，刀尖沿身体轴线刺出；不取代 6A 的上挑 | 直接地面接近和距离较远时的 D 系入口（新增候选） | 命中保持地面状态或产生位置优势，具体是否可接 6A 待数值与空间验证；无无敌 |
| jD「坠线收刀」 | 空中长位移向下穿过目标，以短刀完成最后一次攻击 | 空中 D 系位移攻击、换边与唯一空中收尾 | 命中后结束空中路线；不回到 jA，不增加跳跃资源，落地恢复规则照常 |

首版建议先把 5D 与 jD 作为 D 系核心；6D 是地面中立接近的扩展候选，只有在 5A/5B/5C 与影步假动作无法覆盖距离问题时才加入。

### 5.4 指令必杀技候选

| 招式 | 输入与概念 | 解决的问题 | 主要代价与路线 |
| --- | --- | --- | --- |
| 影步·过隙 | `236C`；短距离向前穿过对手，纯假动作，无攻击判定 | 让角色在命中或被防后的近距离关系中改变站位，体现“执行后换位” | 起手和收招可被读；不能代替确认；终点可被预判 |
| 影步·退位 | `214C`；短距离向后脱离，纯假动作，无攻击判定 | 在不继续赌长链时退出近距离，重新进入测距 | 后退距离有限且终点可预测；被追到时没有攻击保护 |
| 逆裁 | `214D`；长距离向后脱离后以反手短刀横斩 | 以明确的普通击倒结束一轮进攻，让玩家在继续压制与重置之间选择 | 没有无敌；后摇长，挥空或被防承担惩罚；命中进入普通倒地，连段立即结束；不开放 OTG |

推荐的首版特殊技密度是“两种方向的假动作、D 系普通位移攻击、一个明确的击倒收尾”。这样不把每一个影步都变成伤害技能，也不让空中路线拥有过多分支；对手必须先判断 C 假动作还是 D 系攻击，再依据招式帧窗口、终点和后摇反制。

## 6. 必杀技与超必杀技

超必杀不是本轮已确认的运行时能力。若项目之后加入统一的全局能量规则，推荐为本角色设计一招不依赖武器资源的终结技：**「无声定点」**，输入暂定 `236236D`，角色先用影步出现在目标侧后方，再完成一次短刀直线处决演出；它只在命中确认或明确的超必杀窗口中启动，不能因影步换位本身获得无敌或自动命中。若项目不加入全局能量，保留该招的动作概念，不把它伪装成当前可用的普通必杀。

每个候选必杀都必须回答：它解决什么局面；为什么不能直接用普通技替代；如何命中确认；被防／挥空后承担什么风险；是否改变位置、状态或资源；可以接入哪些路线。

`236C` 重设计及 `214D` 普通倒地收尾属于继承任务；`214C`、D 系位移普通技与超必杀属于本轮新增或重设计候选，需用户确认后才进入正式角色规格。

## 7. 路线、反馈与验证目标

当前建议路线如下，均是设计路线而非已验证的可达性证明：

1. **基础空中路线**：`5A → 5B → 6A → jump cancel → jA → jB → jD`。目的，是让玩家先掌握确认、击飞和空中三段节拍。
2. **高回报地面确认**：`5A → 5B → 5C → 6A → jump cancel → jA → jB → jD`。目的，是用更长地面链换取更严格的距离与时机要求。
3. **普通链收束**：`5A → 5B → 5C → 5D`。目的，是在不赌击飞或位置不适合时结束当前攻击，不把每次接触都强迫为浮空路线。
4. **地面换边分支**：在 5B/5C 的命中或被防接触后，按取消规则选择 `236C` 假动作穿过，或进入 5D 的长位移短刀攻击；命中后的方向变化必须由玩家重新确认，不能自动把换边当作安全连段。
5. **空中换边分支**：`6A → jump cancel → jA → jB → jD`。jD 以 D 系长位移短刀攻击改变双方横向关系并收尾，不增加跳跃资源，也不回到 jA。
6. **倒地压起身**：在可用的地面确认后转 `214D`，以普通倒地结束连段并获得起身前行动窗口；对手恢复前，`236C` 可作为穿身假动作，`214C` 可后撤等待，5D／jD 则代表真正的位移出刀尝试。训练场木桩当前没有自主起身选择，因此这里只记录未来对战中的设计目标，不宣称已验证。

每条路线的失败原因都应能被玩家读懂：距离不足、击飞未命中、取消窗口错过、空中招式挥空或影步终点被预测。不能把失败归咎于隐藏资源或随机出现。

帧数、伤害、距离和真实连接在未经过原型验证前只能标为设计初值或目标，不能标为已验证。此轮不运行战斗验证来证明尚未实现的设计。

### 7.1 平衡与反制原则

1. **D 系攻击变体没有无敌**。5D、jD 和 214D 的长位移不能穿过对手的有效攻击判定；位移改变位置，不等于获得防御权。
2. **假动作与攻击变体共用视觉前段，但不共用结算结果**。对手看到相同的起步后，需要根据距离、节奏和经验判断 C 假动作还是 D 出刀；玩家不能在同一输入中临时把假动作改成攻击。
3. **长位移必须付出时间**。攻击出现得越晚，越容易被提前打断；攻击出现得越早，越难形成真正的换边。第一轮调校优先寻找清楚的反制窗口，不先追求“看不见”。
4. **换边后仍要重新确认**。5D 或 jD 造成的左右关系变化，不自动把下一招变成必中；角色的面向、目标状态和距离必须重新进入合法判定。
5. **214D 是收尾而非循环入口**。它命中进入普通倒地并结束当前连段；倒地期间不开放 OTG，不因为压起身目标存在就重置连段。
6. **压起身是位置选择，不是强制命中**。普通倒地后，236C 可以穿身假动作，5D／jD 可以在预测位置出刀，214C 可以后撤等待；这些选择都要留下被防、被打断或走位回避的可能。当前木桩没有自主起身行为，因此这部分是未来对战目标。
7. **空中位移不增加资源**。jD 只消耗一次空中路线机会；不能通过换边重新获得 jump cancel、二段跳或新的空中攻击槽。
8. **角色优势来自决策密度，不来自长时间安全压制**。短刀没有远距离牵制，影步有明显后摇；当玩家猜错输入、距离或终点时，必须承担普通招式和必杀技本身的风险。

### 7.2 设计验收场景

| 场景 | 应体现的角色特征 | 不应出现的结果 |
| --- | --- | --- |
| 地面中立，双方相距一段短刀无法直接命中的距离 | 236C 假动作与 5D 长位移攻击都能改变接触方式，但 D 有可读的攻击窗口 | 5D 因长位移自动无敌或自动命中 |
| 5A/5B 命中后 | 可选择普通链、6A 击飞或位移攻击换边 | 所有路线都无条件进入空中追击 |
| 5A/5B 被防后 | C 假动作与 D 出刀形成压制猜测，挥空仍不能取消 | 被防等同于命中确认，自动取得 jump cancel |
| 6A 命中后 | jA → jB → jD 是一次有限的换边空中路线 | jD 回到 jA、自动续期空中资源或循环 |
| 214D 命中后 | 连段结束，普通倒地和起身前位置窗口清楚 | 倒地目标被 OTG，或倒地被伪装成普通地面硬直 |
| 普通倒地后的压起身 | 236C／5D／214C 提供可读的假动作、攻击与后撤选择 | 假动作完全安全，或攻击变体无论如何都无法被防 |
